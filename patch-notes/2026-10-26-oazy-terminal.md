### Oazy Terminal
- **Oazy has its own terminal.** PowerShell, Command Prompt, your WSL distros, Git Bash and Claude Code run in an Oazy glass window, on the same Windows pseudoconsole Windows Terminal uses, so everything works: full colour, mouse, Unicode and emoji. The Terminal icon on your taskbar opens it, and so do Command Prompt and PowerShell from Start.
- **Made for Claude Code**: the Claude Code pin opens it in a tab, colours and mouse work, Shift+Enter starts a new line in your prompt, and copied files paste as their paths.
- **Tabs and split panes**: Ctrl+Shift+T for a new tab, the arrow next to + to pick a shell, Alt+Shift+D to split, Alt+arrows to move between panes and drag the gap to resize. Drag tabs to reorder, middle-click to close.
- **Find** with Ctrl+Shift+F, **copy** with Ctrl+C when text is selected (otherwise it stops the running command as usual), **paste** with Ctrl+V or a right-click menu. Links open in your browser.
- **Make it yours** from the gear: the shell it opens with, the font (JetBrains Mono comes with it), text size (or Ctrl+mouse wheel), line spacing, cursor and how much glass shows through.
- Closing or updating Oazy never closes your shells. Prefer your old terminal? Switch "Open terminals in Oazy Terminal" off in Settings.
