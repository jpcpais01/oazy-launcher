### Task manager, right on the taskbar

- A new **Task manager** button lives on the taskbar for good. Click it and a glass card rises from it, with a little tail pointing back at the button.
- Every app is one row: its windows and all the helper processes it started, with CPU and memory for each, plus live CPU and memory graphs for the whole PC.
- **End** sits on every row. Apps that might have unsaved work (Word, VS Code, Photoshop…) and Windows' own processes ask once before ending. If Windows needs admin rights, the button turns into **Admin** and asks Windows for you.
- Background programs and Windows processes fold away under their own headings. The parts Windows can't run without show a shield instead of End.
- Search, sort by CPU, memory or name, and click any row for **Switch to**, **File location** or **What is this?**
- It's also in Start and search, and you can right-click the taskbar for it. It only checks what's running while it's open, so it costs nothing the rest of the time.
