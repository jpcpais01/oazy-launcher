### Claude app finds your Claude Code
- **The Claude app looks harder for Claude Code**: on your PATH as it is right now, in npm, pnpm, bun, scoop and winget's folders, and in the copy the Claude desktop app keeps for its own Claude Code. If it still can't find it, **Find it myself…** lets you point to it once.
- **Installing it shows what's happening**: the install tab says what it's doing instead of sitting blank while it downloads, and the Claude app notices the new install by itself when you come back to it.
