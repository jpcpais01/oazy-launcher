### Send pictures and files to Claude

- **Pictures**: Claude in the orb popup can now see pictures. Paste a screenshot with **Ctrl+V**, drop an image on the popup, or pick one with the new **paperclip** next to the box. Big photos are shrunk automatically so they send quickly.
- **Files**: drop any file (or folder) on the popup or pick it with the paperclip, and Claude reads it from your PC, so PDFs, spreadsheets, code and documents all work.
- **See what you sent**: pictures show as thumbnails and files as small chips, both in the box before you send and in the chat after. Past chats show them too.
- **Oazy Claude**: the paperclip there now takes any file, not just pictures, and dropped files work the same way.
