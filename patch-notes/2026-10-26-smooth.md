### Smoother everywhere
- **Scrolling glides.** Every list in Oazy (All apps, search results, Library, Settings, patch notes) now scrolls smoothly with the mouse wheel or touchpad, and picks up speed when you flick quickly. Moving through the Library with the keyboard or a controller glides along too.
- **Start, search and the tray pop-ups open instantly.** Oazy keeps their windows ready instead of creating a new one each time, which was the little hitch you felt on every open.
- **Higher, steadier frame rate.** Only the desktop waits for your screen's refresh now, so the taskbar, Start and Oazy's windows no longer slow each other down.
- Start keeps its tiles between opens, search reuses its rows as you type, and every effect is prepared right after Oazy loads, so the first open is as quick as the rest.
