# Patch notes

Every change merged to `main` adds one file here. CI collects the files added
since the previous release and publishes them as that release's notes, which
is also what players see in the in-app **What's new** screen.

- Name: `YYYY-MM-DD-short-slug.md`
- Write for players, not developers: what they will notice, in plain words.
- Format: a `###` headline, then `-` bullets. **Bold**, *italic* and links work.
